HOW TO USE:

1. Find your htdocs folder in the following directory:

    C:\xampp\htdocs

    Download the repository in that directory

2. Open XAMPP and run Apache and MySQL

3. Go to: http://localhost/22k_IS/index.html (index.html serves as the webpage for the application)
